# 質化筆記 — 閱讀前必讀

這 54 份筆記是 Phase 3b 的 LLM 質化抽讀結果,對象是公開的第三方 repo。
公開發布前請先理解以下四點,它們決定了這些筆記該怎麼被讀:

### 1. 這些是**靜態觀察**,不是漏洞揭露

所有判定都來自**公開原始碼的靜態閱讀**(Iron Rule 7:從未執行任何 clone 內的檔案)。
沒有任何一則是可利用漏洞的揭露,也沒有任何一則宣稱作者有惡意。
標記為 `⚠ injection-suspect` 的意思是「**這段文字在結構上與 prompt-injection 載體同構**」,
不是「這個 repo 是攻擊」——多數情況下作者的意圖顯然是善意的(例如安裝器要求 agent 照做)。

### 2. **樣態是發現,repo 只是證據**

rubric 要記錄的是「哪些**寫法**會擴大 agent 的權限面」。具名 repo 出現在筆記裡,
是因為它提供了該樣態的具體實例可供查證——換成任何其他有相同寫法的 repo,結論相同。
請不要把這些筆記讀成 repo 的排名或黑名單。

### 3. 快照時效:**2026-08-16 / 17**

repo 內容會變。這裡的每則觀察都對應當時的 `clone-manifest.json` 所記錄的 commit。
**你今天看到的該 repo 可能已經不一樣了。**

### 4. 每則判定都附引文,可自行覆核

我們刻意要求引用原文(≤120 字元)而非概括,就是為了讓讀者能自己回去查、
自己判斷我們讀得對不對。**如果你發現我們讀錯了,那就是讀錯了**——
本研究自己就記錄過 7 次 rubric 誤判與 1 次審查者誤判
(見 [`../self-audit-round2.md`](../self-audit-round2.md))。

## 抽樣方式(為什麼是這幾個檔)

每個 repo 讀的是 `feature_matrix.json` 的 `phase3b_sample` 欄位所列的 ≤5 個 SKILL.md,
該清單由**確定性規則**產生(max-lines 1 個 + median-lines 1 個 + 其餘依 path sha1 排序遞補,
並對 skill 目錄名去重以避開翻譯鏡像)。這是為了防止 cherry-pick——
不是我們挑最好或最差的來讀。

集合型 repo(如 897 個 skill 的 ECC)因此只讀了 5 個,**筆記不代表整個 repo 的全貌**。
