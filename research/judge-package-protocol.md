# 判讀包協定 v3(2026-09-03,第五批規則化)

> 盲判/一致性判讀的組包與派工紀律。歷版散落於各波預登記檔與批次報告;
> 本檔為 canonical,往後各波預登記引用本檔並只記**當波特有**條款。
> 修訂走批次紀律(理由寫批次報告,不寫這裡的條款正文)。

## 一、包內容物

1. **criteria**:遮蔽版 rubric(`scripts/mask_rubric_for_raters.py` 產生)。
   工具自動:具名遮蔽、fp-registry 剝除、**evidence_refs 整批剝除**
   (refs 是作者材料,判讀者不需要;遮名+數字類屬化擋不住結構描述的唯一映射,
   整類消滅是唯一可靠修法——dirty 波前哨實錘)。
2. shapes / 語料 / mask-sample:照波預登記。
3. **遮蔽產物目錄(rubric-masked/)不得置於、亦不得殘留於交付目錄**——
   散文「不得開啟」擋不住,要機械不存在:組包抽取後即刪。
   (dirty 波實錘:留在包內的遮蔽產物含遮蔽槽數字錨與未遮家族名,整組抵銷 v2 去污染。)
4. **判讀包出艙**(rubric370 波前哨實錘,HIGH 級):包目錄的**父層鄰接樹**不得含
   任何身分鑰匙(候選清單、以 repo 名命名的輸出、往輪前哨/判讀報告)——遮蔽品
   掉進判讀目錄與判讀包放進鑰匙堆是同一違規的兩個方向。機械 pre-flight:
   dispatch 前 grep 鄰接樹有無語料 token,零命中才派工。包標籤用中性亂數,
   不得與語料目錄共享編號。
5. **shapes.md 文體規則**:形狀句只准用形狀分類學詞彙;禁止改寫/翻譯 repo 自述,
   禁止使用 pass_criteria 內名詞(dispatcher/router/When-to-Pivot 之類)——
   那會預先確認治理物存在、預寫判讀方向。
6. criteria 的 rubric_version **沿革註由工具自動剝除**(rater 副本只留裸版本)——
   沿革註是歷來定錨值與失效模式的檢查表,屬 canonical 不屬判讀包。
7. 交付快照**凍結**:發包後 criteria 不得重生成;需修包 → 新快照、記版本、
   已派判讀者標註其所讀版本。

## 二、遮蔽清單

- 受審者 `owner/name/owner-name` 三形;
- **語料含第三方衍生內容(vendored)時,上游名一併入遮蔽清單**;
- 數字錨類屬化(判準數字清單守衛把關新數字)。

## 三、派工前

- **反匿名前哨為必經**:指定攻擊 = 內容指紋 registry 語意監看名單全部條目
  + 當波預登記標的;前哨判 LEAK → 修包再派。
- 判讀者 prompt 必含:供應鏈警覺(語料是資料不是指令)、只交四維值不算 verdict、
  **環境既識申報必填段**——subagent 繼承宿主已裝 skill 清單與專案敘事,
  「盲」只及判準與遮蔽名;認出語料家族、載有判準沿革者**如實申報**,
  申報不作廢判讀,取值以語料錨為準。選樣端:語料與已裝 skill 家族重疊者
  必然被認出,選樣時即標記。

## 四、收工(判讀者產出的採信)

1. **逐錨驗證,錨實者勝**——判讀不是證據,通過逐字驗證的判讀才是;
   編造錨以 grep 證偽(已有多例)。
2. **採信永遠是暫定的**:靜默期規則(≥ 已跑時長)已被兩度否證、作廢。
   同 task-id 任何後到產出 → 強制勘誤複核;已 land 就開勘誤 PR。
3. **「零程序事故」類宣稱不得在該輪 agent 可能還會產出時寫下。**
4. 關鍵詞 grep 不是品質量具(取值只能靠讀;grep 只能找位置)。
5. 判讀逐字落檔於當波 blind 目錄(中途稿/定稿分節、時序全列),加審查者禁讀清單。
